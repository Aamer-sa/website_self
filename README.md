# Aamer ♥ Shaista — Forever Story v4

## Add your files
Put these files beside index.html before deploying:

```text
image1.png
image2.png
image3.png
image4.png
proposal.gif
celebration.gif
```

- image1–image4: your engagement photos
- proposal.gif: small ring-box / teddy proposal animation
- celebration.gif: happy couple celebration animation

If a GIF is missing, the website automatically shows a romantic emoji fallback, so it will still work.

## Test
Extract the ZIP, keep all files in the same folder, then open index.html in Chrome.

## Deploy GitHub Pages
1. Create a GitHub repository.
2. Upload index.html, yes.html, style.css, script.js, yes.js, README.md, image1–4.png, proposal.gif, and celebration.gif to the repository root.
3. Go to Settings → Pages.
4. Choose Deploy from a branch, select main and /(root), then Save.
5. Wait for GitHub to publish and test the URL on mobile.

## Edit after deployment
Open the repository, select a file, click the pencil icon, commit changes, wait 1–3 minutes, then refresh.

## No-button rule
The No button moves to a clearly different safe position inside the proposal area. It never overlaps or comes too close to the Yes button.
